# AI-Guru V51.7 — Video-DNA integration

Integrated the attached Video-DNA corpus into **General Class** without introducing a Manim runtime.

## Runtime role
- Existing 69-entry K–12 Visual DNA remains active.
- Attached 231-entry Video-DNA corpus is an additional General Class visual-grammar retrieval layer.
- Retrieval prefers portable, non-duplicate, non-character-driven entries and favors S/A/B quality tiers by score.
- The planner receives construction order, visual arc, motifs, beat mix, pacing and QA guidance.
- DNA is converted into AI-Guru visual actions/nodes; it never asks the browser to execute source code.
- Problems & Formulae's separate 20-reference-video DNA remains unchanged.
- Konva/browser whiteboard remains the renderer; no Manim dependency was added.

## Added assets
`data/ai-guru/video-dna/general/` contains the 231-entry corpus plus its index, retrieval index, archetypes, palette and style metadata.
