# AI Guru V51.6 — Separated Teaching Modes

## Normal Classroom
Normal classroom teaching now uses only the curated K-12 general-teaching Visual DNA / visual-template library. It can still explain and solve problems encountered while teaching, using the verified math solver and general visual grammar. The 20 physical problem-solving references are excluded from classroom strategy selection.

## Problems and Formulae
Material Studio now includes a new **Problems and Formulae** material type beside MCQ, Revision Notes, Worksheet, etc. This practice/revision material uses the 20-reference Problem-Solving Visual DNA library to shape worked solutions and exercises. It never uploads or watches the MP4 files during ordinary generation.

## Isolation rule
- Classroom → general-teaching Visual DNA only.
- Problems and Formulae → 20-reference problem-solving DNA (top relevant patterns only).
- MCQ / Revision / other material types remain independent and do not activate the 20-video style library.
- Physical reference-video watching remains opt-in diagnostic/enrichment only and is not required by Problems and Formulae.
